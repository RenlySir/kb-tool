# KB Tool Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Go CLI that ingests files and Git repositories into a TiDB-backed knowledge base with automatic tags.

**Architecture:** The CLI delegates source collection, tagging, ingest orchestration, and TiDB persistence to focused internal packages. TiDB stores documents, normalized tags, and document/tag links.

**Tech Stack:** Go 1.24, TiDB/MySQL protocol, `github.com/go-sql-driver/mysql`, Git CLI.
